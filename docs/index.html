Find Humanin and SHLP1-6 where they are encoded: inside MT-RNR2.

HumaninFinder locates the mitochondrial-derived peptides of the 16S rRNA gene in mitogenomes, contigs and nuclear assemblies (NUMTs). It finds each peptide by its homologous position in MT-RNR2, reads the species' own reading frame there, and states exactly which evidence supports every call.

Get started Source on GitHub Documentation
$pip install humanin-finder

Why a dedicated tool

Humanin and the six small humanin-like peptides are encoded by short open reading frames that overlap a structural RNA. Generic gene finders skip them, and MT-RNR2 has many nuclear copies, so a sequence match alone does not tell where a copy comes from or whether its frame is intact.

Position first

Peptides are located by their homologous position in MT-RNR2 with nhmmer, not by matching the human peptide, so divergent orthologues are still found.

The species' own frame

The ORF is read from the local start codon under the genetic code you choose, and classified as Complete, Incomplete or Interrupted.

Graded evidence

Names say how far the evidence goes: Humanin, Humanin_position or Humanin_domain, with the Pfam domain PF15040 as independent support.

Mitogenomes and NUMTs

predict gives the best frame per record; scan reports every locus in contigs and chromosomes that carry nuclear copies.

Circular genomes

Loci that cross the origin of a circular mitogenome are read through it and written with the GFF3 convention for circular sequences.

Standard, traceable outputs

CSV, FASTA, GFF3 and BED, plus a JSON record with the command, the options and the SHA-256 of the input. No external binaries: HMMER runs in memory.

In silico evidence only A reported frame is a homology-based candidate. HumaninFinder makes no claim that a peptide is transcribed, translated or functional.

How a frame is called

Four steps, each reported in the output so that every call can be traced back to its evidence.

Locate the locus

nhmmer searches the record with two profile HMMs built from vertebrate mitogenomes: the whole MT-RNR2 gene and the Humanin core. Thresholds are calibrated above the paralogous bacterial and plastid 23S and the nuclear 28S rRNAs.

Read the frame

The species' own ORF is read from the start codon nearest the mapped human one, within 6 codons. Humanin uses the requested code; SHLP1-6 use the standard code, under which SHLP1-4 give their published sequences.

Assign a status

Complete: start through an in-frame stop. Incomplete: no start, or no stop within 60 codons. Interrupted: an in-frame stop inside the homologous span.

Name by evidence

Humanin at a vertebrate-like locus, Humanin_position outside the vertebrate pattern, Humanin_domain for a PF15040 domain outside any locus.

Evidence tiers

Every frame HumaninFinder reports is E1: in silico, at a homologous position conserved across clades. The literature tier of the human peptide (E2-E4) is copied only when the frame found is identical to it.

Outputs

  • CSV: one row per frame, with coordinates, scores and evidence
  • FASTA: peptide sequences
  • GFF3 and BED: tracks for genome browsers, circular-aware
  • JSON: provenance (command, options, input SHA-256, version)

Install

Python ≥ 3.10. Dependencies: Biopython, click and pyhmmer. HMMER runs in memory, so there are no external binaries to install.

The released package from PyPI.

pip install humanin-finder
humanin-finder setup

The recipe is under review in bioconda-recipes#71446; this command works once it is merged.

conda install -c conda-forge -c bioconda humanin-finder
humanin-finder setup

A clone in its own conda environment, built from environment.yml (editable install, with pytest and ruff).

git clone https://github.com/LaBiOmicS/humaninfinder.git
cd humaninfinder
micromamba env create -f environment.yml   # or: conda env create -f environment.yml
micromamba activate humaninfinder
humanin-finder setup

The human reference mitogenome ships in examples/. Under the vertebrate mitochondrial code, treated as circular, it gives seven complete frames at the expected locus.

Scope and limitations

  • Homology only. Evidence is the position in MT-RNR2 and/or the PF15040 domain. Expression and function have to be shown experimentally.
  • Vertebrate profiles. The profiles were built from vertebrate mitogenomes; outside vertebrates a locus is named _position at most.
  • Automatic genetic code. -g auto treats records ≤ 50 kb as mitochondrial and covers vertebrate codes only. Other mitogenomes, and NUMTs in short nuclear contigs, need an explicit code.
  • Beta. The command-line interface and outputs are expected to stay stable, but may still change before 1.0.0.
