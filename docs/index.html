Find Humanin and SHLP1-6 where they are encoded: inside MT-RNR2.

HumaninFinder locates the peptides of the 16S rRNA gene in mitogenomes, contigs and nuclear assemblies. It finds each one by its homologous position in MT-RNR2, reads the species' own reading frame there, and states which evidence supports every call.

Why a dedicated tool

Short frames inside a structural RNA, with nuclear copies everywhere.

Generic gene finders skip open reading frames that overlap an rRNA, and MT-RNR2 has many nuclear copies (NUMTs). A sequence match alone does not tell where a copy comes from or whether its frame is intact.

01

Position first

Peptides are located by their homologous position in MT-RNR2 with nhmmer, not by matching the human peptide, so divergent orthologues are still found.

02

The species' own frame

The ORF is read from the local start codon under the genetic code you choose, and classified as Complete, Incomplete or Interrupted.

03

Graded evidence

Names say how far the evidence goes: Humanin, Humanin_position or Humanin_domain, with the Pfam domain PF15040 as independent support.

04

Mitogenomes and NUMTs

predict gives the best frame per record; scan reports every locus in contigs and chromosomes that carry nuclear copies.

05

Circular genomes

Loci crossing the origin of a circular mitogenome are read through it and written with the GFF3 convention for circular sequences.

06

Traceable outputs

CSV, FASTA, GFF3 and BED, plus a JSON record with the command, the options and the SHA-256 of the input.

In silico evidence only. A reported frame is a homology-based candidate. HumaninFinder makes no claim that a peptide is transcribed, translated or functional.

Online version

Try it now, without installing anything.

The web version runs HumaninFinder inside your browser through Pyodide, with a WebAssembly build of HMMER. Paste or upload a FASTA file, choose the options, and download the same tables and tracks as the command-line tool.

  • Your sequences never leave your computer: there is no server.
  • Same code and same outputs: byte-identical to the installed tool on the validation sets.
  • predict and scan, any NCBI genetic code, circular genomes, every advanced option.

Limitations of the web version

For anything beyond these limits, install the command-line tool.

Sized for mitogenomes, not genomes
A browser tab has limited memory. Up to a few hundred mitogenomes per run works; whole nuclear assemblies and NUMT scans of chromosomes need the installed tool.
One processor core
The browser runs Python on a single thread. Expect about one second per mitogenome, so several minutes for a few hundred.
First load needs the internet
The engine (about 15 MB) is downloaded on the first visit and then cached. Keep the tab open while a run is in progress.
A recent browser
WebAssembly with SIMD is required: current Chrome, Edge, Firefox or Safari (16.4 or later).
Interactive only
One input at a time, no scripting or pipelines. For batches, workflows and reproducible runs, use the CLI; each web run still records its options in run.json.

Method

How a frame is called.

Four steps, each reported in the output so that every call can be traced back to its evidence.

Locate the locus

nhmmer searches the record with profile HMMs of the whole MT-RNR2 gene and of the Humanin core. Thresholds sit above the paralogous bacterial and plastid 23S and the nuclear 28S rRNAs.

Read the frame

The species' own ORF is read from the start codon nearest the mapped human one, within 6 codons. Humanin uses the requested code; SHLP1-6 the standard code.

Assign a status

Complete: start through an in-frame stop. Incomplete: no start, or no stop within 60 codons. Interrupted: an in-frame stop inside the homologous span.

Name by evidence

Humanin at a vertebrate-like locus, _position outside the vertebrate pattern, _domain for a PF15040 domain outside any locus.

Evidence tiers

E1
In silico, at a homologous position conserved across clades. Every frame HumaninFinder reports.
E2-E4
Literature tier of the human peptide (transcript, peptide, activity), copied only when the frame found is identical to it.

Install

Up and running in one command.

  • Python 3.10 or newer, on Linux, macOS or Windows.
  • Biopython, click and pyhmmer, installed automatically.
  • No HMMER binaries to install: pyhmmer runs it in memory.
  • Check the installation with humanin-finder setup.

The released package from PyPI.

pip install humanin-finder
humanin-finder setup

Under review in bioconda-recipes#71446; available once merged.

conda install -c conda-forge -c bioconda humanin-finder
humanin-finder setup

A clone in its own environment from environment.yml, installed in editable mode with pytest and ruff.

git clone https://github.com/LaBiOmicS/humaninfinder.git
cd humaninfinder
micromamba env create -f environment.yml
micromamba activate humaninfinder
humanin-finder setup
Usage

Common recipes.

predict for mitogenomes, scan for every locus in larger assemblies. The default code, auto, covers vertebrates; other taxa need an explicit NCBI code.

Complete mitogenomes, any assembly origin

humanin-finder predict -i mito.fasta -o mito -g 2 --circular

Mitochondrial and standard readings side by side

humanin-finder predict -i mito.fasta -o mito -g 2,1

Every MT-RNR2 copy (NUMTs) in a nuclear assembly

humanin-finder scan -i genome.fa.gz -o numts -g 1

Non-vertebrate mitogenome (insects, code 5)

humanin-finder predict -i dmel_mt.fasta -o dmel -g 5 --circular
Scope

What the evidence covers.

HumaninFinder tells you

  • Where the homologous position of each peptide lies in MT-RNR2.
  • Whether the species' own frame there is complete, incomplete or interrupted.
  • Whether the locus follows the vertebrate pattern, and whether the PF15040 domain is present.

It does not tell you

  • Whether the peptide is expressed or functional: that needs experiments.
  • Much outside vertebrates: the profiles come from vertebrate mitogenomes, so other loci are named _position at most.
  • The right code for a NUMT in a short nuclear contig: pass -g 1.
