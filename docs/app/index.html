Run HumaninFinder in your browser

Paste or upload mitochondrial sequences in FASTA format and get Humanin and SHLP1-6 calls with the same engine as the command-line tool. Results are identical to the installed version.

Runs entirely on your computer. Sequences are never uploaded.

Input

Plain or gzip-compressed FASTA. Up to a few hundred mitogenomes per run.
Mode
auto covers vertebrates only; give the code explicitly for other taxa.

Load the example or paste your sequences, then press Run.
The first run downloads the engine (about 15 MB); later runs start immediately.
